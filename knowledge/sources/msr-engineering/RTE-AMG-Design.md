##Access details for AMG management in AI+R/MSR/RTE:

Minimize risk by limiting access to each project with unique secure groups based on access requirements. 


	• AMG Projects SGs (mail enabled create in  IDWEB)
		○ Permanent SC-ALT PIM enabled SG with "owner" access - Add SC-ALT accounts of your project owners that are entrusted with performing admin tasks. 
		○ Permanent SG with active "reader" role - Add domain accounts that need read only access to said subscriptions
		○ IF NEEDED - Permanent SC-ALT PIM enabled SG with "owner" access with fluid membership - fluid access based on project needs. Example.. Adding an engineer (and removing when finished) to complete a specific task.
