# Service details
**Service Name**: Third-Party License Management for licenses used by T&R
**Service Description**: Managing licenses centrally used by the division including Matlab, Mathematica, Magma, Maple, Overleaf, Alchemer, and SurveyMonkey.

## Service Requirements:
- Licensing Server (MSR-Tools)
- MySecret for login credentials (SurveyMonkey, Alchemer, Matlab)
- Secure Groups and MyAccess for permissions
- Greg/Operations to monitor inbox for access requests and support
- Manual updates for version upgrades and license files on Windows and Linux 
- Access to file shares \\msr-tools\Matlab$, Magma$, Mathematica$

## Costs
- $176k/year Matlab, ($75k) 5-figure/year for Mathematica, $7k/3 years Magma
- Infrastructure costs per month - a VM on an on-prem server
- SES hours per month - 8
- Risks 
  - Over time, some licenses have grown over time and are bloated, consistently raising the annual cost each year.
  - Alchemer does not use SSO, each admin and user must maintain credentials
  - MSR-Tools not internet first
