# Why
Gaia is a bot designed to provide Kusto users in Microsoft self-service tools for managing 1st-party Kusto clusters, falling back on creating ops tickets for issues that cannot be resolved automatically.

# Risks
- Incomplete or inconsistent entry of alerts can cause confusion, or won't alert in ways that are expected
