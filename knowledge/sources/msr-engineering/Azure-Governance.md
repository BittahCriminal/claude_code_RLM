# Azure Governance is the overarching program for managing Azure resources at scale. 

## The key goals of our Azure Governance program in MSR is to provide:
[Cost Management](/Process-and-Reference/Azure/Azure-Governance/MSR-Azure-Governance-Information-and-Links/Cost-Management) 
[Least Privileged Access (LPA)](/Governance/Least-Privileged-Access)
[Management Group Hierarchy](/Process-and-Reference/Azure/Azure-Governance/General-Information-and-Links/Management-Groups)
[Secure Policy Application](/Process-and-Reference/Azure/Azure-Governance/General-Information-and-Links/Azure-Policy)

## In order to fully support a scalable Azure Governance program, the following prerequisites should be met:
- Clean, clear, and consistent data in Service Tree.
- Clear, unambiguous naming conventions (that scale beyond any individual team).
- Well organized Azure resources within subscriptions that combine related items.
