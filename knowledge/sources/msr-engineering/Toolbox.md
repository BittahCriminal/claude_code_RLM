# Why
This is our SES toolbox. It contains things we have investigated with the intent of scaling our impact. Not all of these tools will make it into our toolbelt. This is an innovation space to ensure we can develop new team capabilities while ensuring we're thoughtful when adopting. 

# Terminology
- Toolbox - This is a collection of the tools we can leverage on occasion
- Toolbelt - These are tools that are so valuable we carry their weight (operational overhead) with us. These tools can be critical dependencies in our standard processes.
- Tool Return on Investment (ROI)- Any tool worth its weight provides more value than cost. This should be a quantifiable measurement. 

# Risks
- Too many tools in our toolbelt weigh us down and reduce agility
- Frequently replacing tools in our toolbelt can give others the perception we're not thoughtful in our adoption
- Not considering new tools can leave impact on the table
- Not balancing innovation with accountability can lead to reduced impact
