# Why
We have services which we want to know, before the customer, when they are having partial or complete outages.

# Terminology
- Toolbox - This is a collection of the tools we can leverage on occasion
- Toolbelt - These are tools that are so valuable we carry their weight (operational overhead) with us. These tools can be critical dependencies in our standard processes.
- Tool Return on Investment (ROI)- Any tool worth its weight provides more value than cost. This should be a quantifiable measurement. 

# Risks
- Incomplete or inconsistent entry of alerts can cause confusion, or won't alert in ways that are expected

# Tool adoption phase
- Toolbelt adoption

# Discovery Template 
- Tool Name - Azure Monitor - Alerts
- Tool description - Alerting methodology for services
- Tool value assessment (ROI)
- Tool training resources
- Tool Support
- Tool impact areas - Monitoring and Alerting
