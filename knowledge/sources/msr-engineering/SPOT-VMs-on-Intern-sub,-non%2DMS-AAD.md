Setup Steps:
1.	Whitelist your “External Test Account” for internal subscription access, [Subscription Approval Process - Overview (visualstudio.com)](https://nam06.safelinks.protection.outlook.com/?url=https%3A%2F%2Fmsazure.visualstudio.com%2FAzureWiki%2F_wiki%2Fwikis%2FAzureWiki.wiki%2F22846%2FSubscription-Approval-Process%3Fanchor%3Dnew-domain-authorization&data=04%7C01%7Ckatie%40microsoft.com%7C9864eaff05444cb1c9ee08d9bf3be949%7C72f988bf86f141af91ab2d7cd011db47%7C1%7C0%7C637751086344896600%7CUnknown%7CTWFpbGZsb3d8eyJWIjoiMC4wLjAwMDAiLCJQIjoiV2luMzIiLCJBTiI6Ik1haWwiLCJXVCI6Mn0%3D%7C3000&sdata=259ezAVILeSAF2rBh1lHpCYfgm6VOj7HF3dwTFmVhNc%3D&reserved=0). This will open up an IcM incident which will whitelist your <External Test Account email>.onmicrosoft.com domain to create internal subscriptions
o	our original "External Test Account" was created with the account owner stuart-bcdtenant@outlook.com Which created a domain Non-MS account.onmicrosoft.com. That domain is what we whitelisted
2.	After the whitelisting process (which can take a week or more depending on approval timing and when they push out changes), go to the "External Test Account" Azure Portal and create an admin account on the whitelisted <External Test Account email>.onmicrosoft.com domain. This must be a "New User" not a "New Guest User" whose email address resolves to your custom domain
o	For our stuart subscription this account was stuart-customdomain@stuartbcdtenantoutlook.onmicrosoft.com
3.	Assign that account with permissions so it can then sign-up for an M365 trial account. Billing Administrator and Global Administrator are overkill but worked.
o	This account needs to be capable of receiving email and without an M365 trial there will be no valid outlook.com mailbox for this account. That is, when you go to outlook.com when logged into this account you will get the error "OwaUserHasNoMailboxAndNoLicenseAssignedException"
o	Note custom on.microsoft.com accounts cannot update DNS TXT records so you cannot use an MSDN Developer M365 account to add your custom domain
o	Instructions for signing up for an M365 trial are here https://docs.microsoft.com/en-us/azure/cost-management-billing/manage/azure-account-for-microsoft-365-subscription
1.	Wait a few hours for the M365 mailbox to be setup and that test emails sent to that address show up
2.	After completing the sign up for the M365 account, using your Microsoft employee Edge profile, visit the ARIS classic website, aka.ms/airs and then put in a “New Registration” request
o	The request needs to be type “Internal Billable Account” and the Account Owner must be an email address on the whitelisted domain (i.e. stuart-customdomain@stuartbcdtenantoutlook.onmicrosoft.com)
o	After that request is approved your whitelisted domain should now be able to access the AIRS 2.0 website to create an internal subscription request
3.	Now you can visit the AIRS 2.0 website, and put in a request to have an internal subscription created, [AIRS Dashboard](https://nam06.safelinks.protection.outlook.com/?url=https%3A%2F%2Fairs.azurewebsites.net%2Fhome&data=04%7C01%7Ckatie%40microsoft.com%7C9864eaff05444cb1c9ee08d9bf3be949%7C72f988bf86f141af91ab2d7cd011db47%7C1%7C0%7C637751086344896600%7CUnknown%7CTWFpbGZsb3d8eyJWIjoiMC4wLjAwMDAiLCJQIjoiV2luMzIiLCJBTiI6Ik1haWwiLCJXVCI6Mn0%3D%7C3000&sdata=G47VSox4uDrKyTaA3V9%2BufiD3wYU%2FPcifUHusScYcM4%3D&reserved=0)
4.	Wait for finance and service tree approval. Then you will get an email sent to your admin account on your whitelisted domain with a link to create an internal subscription
o	(i.e. stuart-customdomain@stuartbcdtenantoutlook.onmicrosoft.com will get an "Congratulations! Your request to create a new Azure Internal Subscription has been approved")
5.	Click that link and create the internal subscription and then you’re all set, your “External Test Account” domain should now have a new Microsoft Internal Azure Subscription which can run Spot VMs
