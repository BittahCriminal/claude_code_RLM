# Report distribution

The Azure consumption reports are sent out every Wednesday via a Power BI subscription. These are created for each report and use a specific mail distribution list that is managed in http://idewb `(Corporate network connection required)`.

**Membership of a report's distribution list is managed by the business owner not RTE.** This can be indirectly via the Cloud Lead but it is important that the business owner approves all additions or removals.

## Report subscription details

Use https://idweb (Corp connection required) to manage distribution membership. All DL aliases start with prefix 'rteconrep' which can be used as a search term in idweb. 

>All PBI Email Subscriptions are managed using the service account 'rtecorep@microsoft.com'. If you are not signed in to the MSIT Power BI platform as this user you will not be able to view or edit any existing subscriptions. The service accounts passwords are securely stored in a service Azure KeyVault.
