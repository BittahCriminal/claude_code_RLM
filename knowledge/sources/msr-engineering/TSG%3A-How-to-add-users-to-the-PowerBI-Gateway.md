Pre-requisite:
- You must already be listed as an Admin for the PowerBI data connection gateway to manage permissions to add other users. Currently Admins are members of MSRINET and those explicitly added to the gateway (As of 11/3/23: Trevor/JordanD/KrisZ/Jim/Wymanc/Arnie)

1. Navigate to the [PowerBI Portal](https://msit.powerbi.com/groups/fd26e2e0-b498-478b-ac30-039597e1c8b7/gateways?experience=power-bi) and click settings and select `Manage connections and gateways`.

![image.png](/.attachments/image-7a95b375-a943-43ee-bad3-e8ccb9f17dbf.png)

2. Select `On-premises data gateway` tab 

![image.png](/.attachments/image-64bd8420-aa6e-4835-b35f-36a6a6e52b10.png)

3. Select PowerBI-GW2, click on the three dots and click Manage Users

![image.png](/.attachments/image-624e2bbe-3ea5-4a8d-9747-3b6a9273bc50.png)

4. Search for the user to add, select them, and if needed, modify the permissions to grant `Admin` access.

![image.png](/.attachments/image-1746189c-0af9-4cc0-83e8-47ce0d5b4f78.png)

5. Click `Share` and that's it!
