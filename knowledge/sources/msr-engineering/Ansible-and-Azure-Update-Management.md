## Overview

We currently use our Ansible configuration management to install and onboard Linux GPU onprem nodes to GCR-patching. Read this [article](https://dev.azure.com/msresearch/MSR%20Engineering/_wiki/wikis/MSR-Engineering.wiki/2282/Ansible) to be more familiar with how Ansible works in GCR

Ansible task for installing Azure patch management Linux agent to onprem Linux Sandbox is under role-gcr_hpcl/tasks/main.yml in our master gcr-ansible code repository
