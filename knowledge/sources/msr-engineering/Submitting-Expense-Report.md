Click on Expense Management

![Picture1.png](/.attachments/Picture1-2f8ac793-b777-44a2-aed5-e10b777d7bf9.png)

Go to the Expense tab

![Picture2.png](/.attachments/Picture2-46261b1f-f3a3-4cb0-a61c-51c8c1ac1964.png)

Select the expenses you need to complete and click on New Expense report
![Picture3.png](/.attachments/Picture3-82439107-7149-4b24-bb4c-4a56a391cd4f.png)

Name the expense report and add the Interim approver

![Picture4.png](/.attachments/Picture4-07ea678d-227d-438b-9372-a851bea101aa.png)

Select _edit_ to change category.

![Picture5.png](/.attachments/Picture5-a9418325-9027-4518-9d4f-56e92758921a.png)

Click on _Actions_ to attach _receipts_ and add _guests_

![Picture6.png](/.attachments/Picture6-d03a492d-ab89-4d97-a267-f57cf84b9c0b.png)

Upload receipts by browsing your files. Click okay once you receive the notice of “File uploaded…” on top of page.

![Picture7.png](/.attachments/Picture7-63a2d5b3-d2b4-4cbd-a5ca-f144fd41bfcd.png)

Once receipt is attached click _Save and continue_
![Picture8.png](/.attachments/Picture8-99d57722-9754-401b-a3a9-6c11a1034810.png)



To add guests and select New for each person needed to be add.
![Picture9.png](/.attachments/Picture9-3a6bd667-464b-4491-87ae-c9b2dabe5377.png)
![Picture10.png](/.attachments/Picture10-085a0b02-08e6-4628-be68-263b6db2e1b0.png)


Edit the Cost Center or IO by selecting edit next to Financial Dimensions or Action arrow. 
![Picture19.png](/.attachments/Picture19-06db613e-d6c8-45fc-97de-ff39b0996a8d.png)
When finished with report select _Save and Close_ or _Submit_
![Picture16.png](/.attachments/Picture16-30b8559c-5b4a-4f83-9850-c8b6e0b686b2.png)

If you save, the draft can be found on the Reports tab.
![Picture17.png](/.attachments/Picture17-b6b7d8f3-1353-4e34-932d-cd7a3d047266.png)

If you finished select submit, enter a comment, and select submit again.
