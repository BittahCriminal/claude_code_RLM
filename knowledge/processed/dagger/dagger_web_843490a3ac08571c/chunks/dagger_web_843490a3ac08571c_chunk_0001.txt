### Modify a copied directory or remote repository in a container​

When a host directory or file is copied or mounted to a container's filesystem, modifications made to it in the containerdo not automatically transfer back to the host.

Data flows only one way between Dagger operations, because they are connected in a DAG. To transfer modifications back to the local host, you must explicitly export the directory or file back to the host filesystem.

When working with private Git repositories, ensure thatSSH authentication is properly configuredon your Dagger host.

Stdout(ctx)	if err != nil {		return "", err	}	// get value	getter, err := redisCLI.		WithExec(append(args, "get", "foo")).		Stdout(ctx)	if err != nil {		return "", err	}	return setter + getter, nil}
