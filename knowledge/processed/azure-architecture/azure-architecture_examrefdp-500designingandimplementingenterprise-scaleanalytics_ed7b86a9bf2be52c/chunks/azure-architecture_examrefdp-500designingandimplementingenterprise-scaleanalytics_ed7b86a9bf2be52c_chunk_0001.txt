Power BI allows you to work with datasets well in excess of gigabytes even after Power BI auto-

following issues:
 ■ Speed—Dataset refreshes may take a very long time, preventing you from displaying 
the information in a timely manner.

precious RAM, CPU, and network bandwidth.
 ■ Reliability —Long-running queries to data sources may time out or fail, resulting in 
dataset refresh failures.

Spark magic commands are commands used to interact with the Spark cluster from the note-

from datetime import datetime

SELECT
    day_of_month,
    MIN(tip_amount) AS minTipAmount,
    MAX(tip_amount) AS maxTipAmount,
    AVG(tip_amount) AS avgTipAmount,
    AVG(fare_amount) AS avgFareAmount,
     AVG(total_amount) as avgTotalAmount
FROM taxi
