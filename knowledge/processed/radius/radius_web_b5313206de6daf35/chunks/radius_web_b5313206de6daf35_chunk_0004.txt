### Environment parameter

Theenvironmentstring parameter is automatically injected into your Bicep template using the environment ID value specified in your defaultworkspace. This value can also be overridden with the rad CLI:rad deploy --params environment="/planes/radius/...".


```
environment
```


```
rad deploy --params environment="/planes/radius/..."
```

To access the auto-injected value, specify anenvironmentstring parameter in your Bicep file:


```
environment
```
