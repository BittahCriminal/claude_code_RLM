🎯 HOW TO USE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CLAUDE CLI (Original):
  $ claude
  /rlm context=file.txt query="your question"

GITHUB COPILOT CLI (New):
  $ copilot
  "Process file.txt using RLM and answer: your question"
